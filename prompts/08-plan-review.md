# Stage 8 — Plan Review

Verify input snapshots and review `PLAN.md` against the repository, approved upstream artifacts, architecture when applicable, and source authority.

For Standard and Full, correct `PLAN.md` and create or update `PLAN-REVIEW.md` from `templates/PLAN-REVIEW.template.md`.

For Lite, complete the second review pass in `IMPLEMENTATION-BRIEF.md` after first-pass corrections.

Challenge repository assumptions, scope, ordering, dependencies, task size, integration, migration, compatibility, accessibility, responsiveness, states, validation, regressions, abstraction, security, privacy, deployment, rollback, source integrity, and traceability.

Record `PLANREV-*` findings, impact, evidence, correction, plan changes, remaining risk, and status.

End with exactly one status:

- `Ready for task decomposition`
- `Ready with documented risks`
- `Blocked by unresolved technical decisions`

Update `WORKFLOW-STATE.md` and report corrections, residual risks, blockers, and next permitted action.
